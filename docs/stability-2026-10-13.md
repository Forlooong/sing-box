# Debian 12 稳定性修复与验收

本轮针对更新中断恢复、订阅版本确认、证书同步隔离、默认第二个 REALITY 节点四项问题，
并将仅订阅内容的发布与代理服务操作分开。保持现有统一项目，在模块边界上逐步解耦；
尚不新增独立订阅项目或在同一主机安装第二套竞争的 `sb` 入口。

## 已取得的证据

2026-10-13，候选包部署到既有 Debian 12 amd64 测试机。包 SHA-256 为
`dd9f0aea18787d49c17ca912b211fdce85bacd62196b689f1776e9e637ba36e3`。
最终 WSL root 和 Debian 12 root 完整回归均为 **189 项通过，无跳过**。
部署过程使用候选生成器、独立恢复入口和正式文件事务，运行时逐项与候选内容匹配。

| 检查 | 结果及范围 |
| --- | --- |
| 更新中断 | 真实子进程在运行时替换中骤停；独立入口恢复、恢复再次骤停及已撤销令牌回归通过 |
| 订阅版本 | 实际 HTTP 服务保留旧 bundle 时拒绝候选提交并回滚，正常候选需 generation 一致 |
| 证书同步 | 真实证书和 TLS fixture、坏域名隔离、持久重试、进程骤停及域名/旧服务退役回归通过；两服务均延后激活时，健康副本仍保持服务可读权限 |
| REALITY 多用户 | 实际 sing-box/Mihomo 验证同监听第二用户、另一 SNI 用户；删除第一用户后另外两者仍可连接 |
| 公网数据通路 | 部署前后分别验证 REALITY/HY2 请求、错误 UUID/证书 pin 拒绝、恢复正确凭据后成功 |
| 订阅解耦实机 | 停止代理核心时修改并还原订阅名称，核心保持停止；Nginx/订阅 PID、核心配置和凭据保持不变 |
| 证书重试实机 | 对当前有效证书填入待激活队列，实际重载 Nginx、核对握手证书并重启/探测核心，队列清空 |
| 身份与收尾 | 网站、域名、节点、订阅名称和令牌与部署前一致；全栈检查通过，无未完成事务 |

实机证书重试使用当前有效证书，没有申请新证书或模拟生产证书自然过期。
订阅解耦验收提前设置两分钟核心自动恢复任务，并在验证结束后恢复核心和撤销该临时任务。
证书副本不支持通用手工回滚，需修复受管 lineage 后同步；未完成事务仍能恢复。
较新的证书副本事务不会阻挡无文件交集的普通回滚，有交集时明确拒绝覆盖新证书。

## 持续客户端验证

工具见 [client-soak.md](client-soak.md)。使用完整公网订阅、两个持续 Mihomo 进程，
每 30 秒分别通过 REALITY/HY2 请求网站，每 5 分钟在原进程刷新订阅。
同时观测服务器服务状态、PID、自动重启次数、内存和订阅 generation。
强制全局代理用于确认测量通路，因此不把成功请求解释为规则分流决策正确。

首次启动在规则集就绪阶段失败，未开始一小时计时；当次服务器监测 132.529 秒，
服务状态、PID 和自动重启次数均稳定。诊断确认 17 个规则中有一个初次下载超时，
未生成缓存；工具加入总预算 120 秒、单规则最多两次主动重试，仍要求全部规则实际加载。
公网短测验证两协议各两次请求、同 PID 刷新及最后存活检查通过，没有以缓存替换公网下载。

最终一小时观测于 2026-10-13 15:01 UTC 启动（客户端准备成功后单独计满 3600 秒），
目前尚在执行，不以短测或 fixture 代替最终结果。

## 当前适用范围

这些证据只支持指定 Debian 12 amd64、REALITY TCP/Vision 与 HY2 的验收。
Debian 13、Ubuntu 24.04、ARM64、客户端 GUI、真实旧 Caddy 部署迁移、
生产证书自然续期、多地区网络质量、长连接吞吐和多日运行尚未据本轮结果验收。

当前保持统一安装和节点管理有利于继续利用已实现的网站、SNI、证书与恢复流程。
仅订阅名称、模板、元数据、已有域名下的路径/别名、令牌和已启用规则的快照更新走订阅范围；
域名、端口、节点凭证、启用规则定时器和程序升级仍做完整校验。
未来需要支持多种外部代理部署时，再提取独立适配接口和命令，保留上游 `sb` 的所有权。
